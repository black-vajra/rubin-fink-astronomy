# Rubin Historical Research · July–November 2026

Study all available Fink LSST alerts in the inclusive UTC interval July 16–November 15, 2026. This is a separate workstream covering the same extragalactic watch and moving-object objectives as the live project.

## Data and reports

- The complete compact alert export is topic `ftransfer_lsst_2026-11-19_639723`, with 1,043,458 expected alerts and a portal estimate of 1.39 GB. It contains diaSource, diaObject, ssSource and mpc_orbits with no alert filters. These sections retain measurements, flags and available known-object orbit/distance information. Catalog matches and classifier annotations remain available in the four individually retrieved watchlist histories. Image cutouts can be obtained individually as needed.
- The earlier full-packet topic `ftransfer_lsst_2026-11-19_268035` was submitted but is superseded for this work. Its estimated 136.33 GB is not part of the local download workflow.
- `data/object-*.json` retains the complete API responses for the four watched objects. Analysis applies the UTC interval locally and groups each filter separately.
- `data/statistics-*.json` records the five monthly API responses. Thirteen nights have entries in the selected interval, all between October 30 and November 15. Missing statistics entries remain unknown coverage.
- `data/ssobulk.parquet`, if present, is Fink's all-known-SSO light-curve snapshot. It updates monthly and can omit November detections. Its broad historical scope is filtered to the project's interval during analysis.
- `data/ssoft.parquet`, if present, preserves the public aggregate physical/phase-model table. Its parameters need quality review before size inference.
- `extragalactic-report.md/html`, `moving-object-report.md/html` and `archive-coverage.md/html` are regenerated by `historical.py`. A full import also produces `import-report.md/html` and an idempotent SQLite index.
- `slow-controls.json` is a training-only shortlist of cataloged slow movers. It is not a validated recovery result.

## Run on Pots

Extract this directory under your home directory. Use Pots' existing `~/rubin-live/venv/bin/python`. It needs numpy, astropy, fastavro and pyarrow.

Run `bash ~/rubin-historical-2026/download-compact.sh` to retrieve the compact topic and generate updated reports. The raw Avro data stay in the project directory. The importer skips unchanged files and commits each file transactionally. A failed file is retried on the next run. It rejects changed files that were already indexed so stale rows cannot silently remain.

Run `~/rubin-live/venv/bin/python ~/rubin-historical-2026/historical.py` to regenerate from downloaded products. `--fetch` retrieves missing watchlist histories and monthly statistics. Existing downloads are retained because this historical interval is fixed.

## Scope and next analyses

Extragalactic report generation merges imported watchlist detections with the retrieved histories, splits by band and compares the latest flux against earlier values. Zero and negative difference fluxes are retained in JSON and the database but excluded from positive-flux magnitude tables. Examine uncertainties, flags, reference versions, seeing and cutouts before attributing variability. The full archive also supports new-candidate triage once indexed.

The moving-object report scans the SSO bulk histories and imported cataloged detections for training candidates with at least three measurements over 30 minutes on one UTC date, rate 0.001–0.1 arcsec/min, and fit residual at most 1 arcsec. Multiple snapshot sources may list the same object separately; reconcile designation and ssObjectId before adding controls. Full-night tests must withhold later labels and use fixed radii plus independently verified detector footprints. Unassociated detections are retained for subsequent unknown-object linking.

The delivered moving-object report states the actual data analyzed. Candidate linking for unknown bodies, orbit solutions, dynamical masses, and Planet Nine identification are further analyses. Brightness-based mass scenarios require distance, reflectivity, density and appropriate photometric calibration. Retain raw evidence and make uncertainty explicit.
